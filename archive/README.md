# Bass + Guitar Duet Etudes

A generated collection of 32-bar duet studies for beginner/intermediate bass and intermediate guitar. The MusicXML files are the canonical source; PDFs and MIDI are rendered exports.

These are original studies that reference broad stylistic traits without quoting source songs.
